# `casa` - NORTH tool (local build only)

Dockerfile for [CasaXPS](http://www.casaxps.com/) via Wine, layered `FROM` the `kherve` image. Unlike `kherve`, this is never built by CI and never published — CasaXPS is a commercial product, and even its free demo has no confirmed redistribution terms. Build it yourself, locally, with your own copy of CasaXPS.

See the [documentation site](https://fairmat-nfdi.github.io/nomad-north-xps/) for the rest: [Explanation](https://fairmat-nfdi.github.io/nomad-north-xps/explanation/explanation.html) for why this stays local-only, [How-to > Build the Image](https://fairmat-nfdi.github.io/nomad-north-xps/how_to/build_the_image.html) for the full build and license-activation procedure, [Reference](https://fairmat-nfdi.github.io/nomad-north-xps/reference/references.html) for configuration.
