# `kherve` - NORTH tool

Dockerfile and desktop-integration config for [KherveFitting](https://github.com/KherveFitting/KherveFitting) on top of `nomad-north-desktop-base` plus `pynxtools[xps]`. Open-source, no license needed — built and published automatically by CI.

See the [documentation site](https://fairmat-nfdi.github.io/nomad-north-xps/) for the rest: [Explanation](https://fairmat-nfdi.github.io/nomad-north-xps/explanation/explanation.html), [How-to > Build the Image](https://fairmat-nfdi.github.io/nomad-north-xps/how_to/build_the_image.html), [Reference](https://fairmat-nfdi.github.io/nomad-north-xps/reference/references.html).
